## ランチャーの考え方

スタート画面は、NAVI CHARACTER のファンタジー世界を入口として使用しています。

ファンタジーの町の画像を大きく見せ、その下に計算ゲームを

- たんじゅんな計算
- ひっ算バトル

の2つに整理しています。

子どもが「何を練習するか」を見つけやすく、タブレットでも押しやすいカード型のUIです。

## 技術

静的な index.html だけで動作します。

外部API、バックエンド、ビルド環境、外部フォントは使用していません。各学習ゲーム本体は、それぞれのGitHub Pagesで動作します。

スタート画面では以下のNAVI CHARACTER素材を使用しています。

https://tt-sensei.github.io/navi-character-/assets/web/fantasy/groups/group-fantasy-town.webp

## GitHub Pages

GitHub Pages で公開すると、このリポジトリを計算バトルのランチャーとして利用できます。
